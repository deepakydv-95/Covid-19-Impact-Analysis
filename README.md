# 🦠 COVID-19 Pandemic Data Analysis & Interactive Dashboard – India

## 📌 Project Overview

The **COVID-19 Pandemic Data Analysis** project is an interactive dashboard developed to analyze the impact and spread of COVID-19 across **India**.

The project uses Python for data cleaning, analysis, visualization, and dashboard development. It helps users understand how COVID-19 cases changed over time and how different states were affected during the pandemic.

The main goal of this project is to convert raw COVID-19 data into meaningful visual insights through an easy-to-use interactive dashboard.

---

## 🎯 Objectives

* Analyze the spread of COVID-19 across India.
* Track confirmed, active, recovered, and death cases.
* Understand COVID-19 trends over time.
* Compare the impact across different Indian states.
* Create interactive charts and visualizations.
* Present complex pandemic data in a simple and understandable format.

---

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data cleaning and data analysis
* **Plotly** – Interactive data visualization
* **Dash** – Interactive web dashboard
* **Bootstrap** – Dashboard styling and responsive layout
* **Jupyter Notebook** – Data exploration and analysis

---

## 📊 Key Features

### 1. COVID-19 Case Analysis

The dashboard provides an overview of:

* Confirmed Cases
* Active Cases
* Recovered Cases
* Death Cases

### 2. State-wise Analysis

Users can analyze COVID-19 cases across different states and identify which regions experienced higher numbers of cases.

### 3. Time-Series Analysis

Interactive charts are used to understand how COVID-19 cases changed throughout the pandemic.

### 4. Interactive Dashboard

The dashboard allows users to interact with the data through filters and dynamic visualizations.

### 5. Responsive Design

Bootstrap is used to create a clean and responsive dashboard that can be viewed on different screen sizes.

📊 Key Insights

 📈 COVID-19 cases in India showed significant fluctuations during different phases of the pandemic.
 🦠 A few states contributed a large share of the total confirmed cases.
 🔴 Active cases increased sharply during major waves of COVID-19.
 💚 Recovery numbers increased steadily as more patients recovered over time.
 ⚠️ Death cases also increased during periods of high infection.
 📅 Time-series analysis helped identify major increases and decreases in COVID-19 cases.
 🗺️ State-wise analysis showed that the impact of COVID-19 varied significantly across Indian states.
 📊 Interactive visualizations made it easier to compare cases, recoveries, deaths, and active cases.
 💡 The dashboard provides a clear overview of how COVID-19 affected India over time.
